# AgentSkillDeck brand

A fanned deck of skill cards, with an amber spark on the card in front: the skills an agent draws from.

| File | Use |
|---|---|
| `logo-mark.svg` | The mark on its own, transparent background |
| `wordmark-dark.svg` / `wordmark-light.svg` | Mark plus name, for dark and light backgrounds |
| `avatar.svg` / `avatar.png` | Square 512 px avatar for the GitHub org and social accounts |
| `social-preview.png` | 1280×640 GitHub social preview |

Colours: ink `#0b0f17`, card `#f3f4f6`, deck `#3d4e78` and `#6077a8`, spark `#ffb224`.
