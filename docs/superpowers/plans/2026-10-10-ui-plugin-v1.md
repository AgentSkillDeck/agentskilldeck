# agentskilldeck UI plugin v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a private Claude Code marketplace repo `AgentSkillDeck/agentskilldeck` whose `ui` plugin provides four design skills, a ~24-guide library, and two dependency-free search scripts (materials, references).

**Architecture:** Markdown skills that route to on-demand guides; guides and scripts are authored once under `plugins/ui/library` and `plugins/ui/tools`, then copied into each skill by a sync script so every skill folder is self-contained. Scripts are plain Node ES modules using built-in `fetch`, with injectable fetch for tests.

**Tech Stack:** Node ≥ 18 (ES modules, `node:test`, `node:util.parseArgs`), no npm dependencies. Claude Code plugin/marketplace JSON. GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-10-ui-plugin-design.md`

## Global Constraints

- Zero runtime and zero test npm dependencies; `package.json` has no `dependencies`/`devDependencies`.
- Node ≥ 18; ES modules (`"type": "module"`).
- Repo license Apache-2.0; LICENSE + NOTICE copied into every skill folder.
- Never ship the strings `uizze`, `UIZZE`, `npx impeccable`, `impeccable context`, or `{{scripts_path}}` outside `NOTICE`, `docs/ATTRIBUTION.md`, `docs/coverage/`, and single-line provenance comments that begin `<!-- Adapted from`.
- Skill names: `deck-design`, `deck-review`, `deck-radar`, `deck-match`. Plugin name `ui`. Marketplace name `agentskilldeck`.
- Scripts never install anything, never print environment variables, send only query terms upstream.
- Request timeout 8000 ms, 1 retry on network error/429/5xx; catalogue caches 24 h under `os.tmpdir()/agentskilldeck-cache`.
- Exit codes: 0 = results or explicit no-match, 1 = usage error, 2 = all sources failed (service error).
- Result limit 1–5, default 3.
- GitHub repo stays **private**; never change visibility.

## Review Focus

1. **Partial upstream failure** (e.g. Fontshare down, Fontsource up): user expects the working source's results plus a one-line warning, not exit 2. Test in Task 3.
2. **Query with no tokens / only punctuation** (`""`, `"  "`, `"!!"`): expect usage error exit 1 with a message, not a crash or "all results". Test in Task 5.
3. **Corrupt or stale cache file** (truncated JSON in cache dir): expect the cache to be ignored and a fresh fetch, not a crash. Test in Task 2.
4. **`--limit` out of range or non-numeric** (`0`, `9`, `abc`): expect clamp to 1–5 for numbers and usage error for non-numeric. Test in Task 5.
5. **Skill copy edited directly instead of library** (drift): `sync --check` must fail and name the file. Test in Task 7.

```js
import { mkdir, readFile, writeFile, stat } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { createHash } from 'node:crypto';

export class ServiceError extends Error {
  constructor(source, message) {
    super(`${source}: ${message}`);
    this.name = 'ServiceError';
    this.source = source;
  }
}

const DEFAULT_CACHE = join(tmpdir(), 'agentskilldeck-cache');

async function readCache(file, ttl) {
  try {
    const info = await stat(file);
    if (Date.now() - info.mtimeMs > ttl) return undefined;
    return JSON.parse(await readFile(file, 'utf8'));
  } catch {
    return undefined; // missing, unreadable or corrupt: refetch
  }
}

export async function fetchJson(url, {
  source, fetchImpl = globalThis.fetch, timeoutMs = 8000, retries = 1,
  cacheTtlMs = 0, cacheDir = DEFAULT_CACHE,
} = {}) {
  const cacheFile = cacheTtlMs > 0
    ? join(cacheDir, createHash('sha256').update(url).digest('hex').slice(0, 32) + '.json')
    : undefined;
  if (cacheFile) {
    const hit = await readCache(cacheFile, cacheTtlMs);
    if (hit !== undefined) return hit;
  }
  let lastError = 'request failed';
  for (let attempt = 0; attempt <= retries; attempt++) {
    let res;
    try {
      res = await fetchImpl(url, {
        signal: AbortSignal.timeout(timeoutMs),
        headers: { 'user-agent': 'agentskilldeck', accept: 'application/json' },
      });
    } catch (e) {
      lastError = e?.name === 'TimeoutError' ? `timed out after ${timeoutMs} ms` : (e?.message ?? String(e));
      continue;
    }
    if (res.status === 429 || res.status >= 500) { lastError = `HTTP ${res.status}`; continue; }
    if (!res.ok) throw new ServiceError(source, `HTTP ${res.status}`);
    let data;
    try { data = await res.json(); } catch { throw new ServiceError(source, 'invalid JSON response'); }
    if (cacheFile) {
      try { await mkdir(cacheDir, { recursive: true }); await writeFile(cacheFile, JSON.stringify(data)); } catch { /* cache is best-effort */ }
    }
    return data;
  }
  throw new ServiceError(source, lastError);
}
```

```js
const STOP = new Set(['a', 'an', 'the', 'for', 'of', 'and', 'or', 'to', 'with', 'in', 'on', 'ui']);

export function tokenize(text) {
  return String(text ?? '').toLowerCase().split(/[^a-z0-9]+/).filter((t) => t && !STOP.has(t));
}

export function scoreItem(tokens, fields) {
  let score = 0;
  for (const { text, weight } of fields) {
    const words = tokenize(Array.isArray(text) ? text.join(' ') : text);
    for (const t of tokens) {
      if (words.includes(t)) score += weight * 2;
      else if (words.some((w) => w.length >= 3 && t.length >= 3 && (w.startsWith(t) || t.startsWith(w)))) score += weight;
    }
  }
  return score;
}

export function rank(items, tokens, fieldsOf, limit) {
  return items
    .map((item, i) => ({ item, i, s: scoreItem(tokens, fieldsOf(item)) }))
    .filter((x) => x.s > 0)
    .sort((a, b) => b.s - a.s || a.i - b.i)
    .slice(0, limit)
    .map((x) => x.item);
}
```

```js
import { fetchJson, ServiceError } from './http.mjs';
import { tokenize, rank } from './rank.mjs';

const DAY = 24 * 60 * 60 * 1000;
const LICENSE_URLS = {
  'OFL-1.1': 'https://openfontlicense.org/',
  'Apache-2.0': 'https://www.apache.org/licenses/LICENSE-2.0',
};

function fromFontsource(f) {
  const pkg = f.variable ? `@fontsource-variable/${f.id}` : `@fontsource/${f.id}`;
  return {
    name: f.family,
    source: 'Fontsource',
    previewUrl: `https://fontsource.org/fonts/${f.id}`,
    license: { id: f.license, url: LICENSE_URLS[f.license] ?? `https://fontsource.org/fonts/${f.id}` },
    install: `npm i ${pkg}`,
    notes: `${f.category}; weights ${f.weights.join(', ')}${f.variable ? '; variable' : ''}; subsets ${f.subsets.slice(0, 4).join(', ')}`,
    _fields: [{ text: f.family, weight: 4 }, { text: f.category, weight: 2 }],
    _category: f.category,
  };
}

function fromFontshare(f) {
  const weights = [...new Set((f.styles ?? []).map((s) => s.weight).filter(Boolean))].sort((a, b) => a - b);
  const w = weights.length ? weights.join(',') : '400,700';
  return {
    name: f.name,
    source: 'Fontshare',
    previewUrl: `https://www.fontshare.com/fonts/${f.slug}`,
    license: { id: 'ITF-FFL', url: 'https://www.fontshare.com/licenses/itf-ffl' },
    install: `<link rel="stylesheet" href="https://api.fontshare.com/v2/css?f[]=${f.slug}@${w}&display=swap">`,
    notes: `${String(f.category).toLowerCase()}; weights ${weights.join(', ') || 'see preview'}; free for commercial use (ITF FFL)`,
    _fields: [
      { text: f.name, weight: 4 },
      { text: f.category, weight: 2 },
      { text: (f.font_tags ?? []).map((t) => t.name), weight: 1 },
    ],
    _category: String(f.category).toLowerCase(),
  };
}

const strip = ({ _fields, _category, ...r }) => r;

export async function searchFonts(query, { limit, category, fetchImpl, cacheDir }) {
  const common = { fetchImpl, cacheDir, cacheTtlMs: DAY };
  const [fs, fsh] = await Promise.allSettled([
    fetchJson('https://api.fontsource.org/v1/fonts', { ...common, source: 'Fontsource' }),
    fetchJson('https://api.fontshare.com/v2/fonts?limit=200', { ...common, source: 'Fontshare' }),
```

```js
import { fetchJson } from './http.mjs';

const DAY = 24 * 60 * 60 * 1000;
export const ANIMATED_FALLBACK = ['line-md', 'svg-spinners', 'meteocons'];

async function animatedPrefixes(common, warnings) {
  try {
    const cols = await fetchJson('https://api.iconify.design/collections', { ...common, cacheTtlMs: DAY, source: 'Iconify' });
    const found = Object.entries(cols).filter(([, v]) => (v.tags ?? []).includes('Contains Animations')).map(([k]) => k);
    return found.length ? found : ANIMATED_FALLBACK;
  } catch (e) {
    warnings.push(`Iconify collection list unavailable, using built-in animated sets (${e.message})`);
    return ANIMATED_FALLBACK;
  }
}

function pickDistinct(icons, limit) {
  const byPrefix = new Map();
  for (const id of icons) {
    const p = id.split(':')[0];
    if (!byPrefix.has(p)) byPrefix.set(p, []);
    byPrefix.get(p).push(id);
  }
  const out = [];
  for (let round = 0; out.length < limit; round++) {
    let added = false;
    for (const list of byPrefix.values()) {
      if (list[round] && out.length < limit) { out.push(list[round]); added = true; }
    }
    if (!added) break;
  }
  return out;
}

export async function searchIcons(query, { limit, animated = false, fetchImpl, cacheDir }) {
  const warnings = [];
  const common = { fetchImpl, cacheDir };
  const params = new URLSearchParams({ query, limit: '64' });
  if (animated) params.set('prefixes', (await animatedPrefixes(common, warnings)).join(','));
  const data = await fetchJson(`https://api.iconify.design/search?${params}`, { ...common, source: 'Iconify' });
  const ids = pickDistinct(data.icons ?? [], limit);
  const results = ids.map((id) => {
    const [prefix, name] = id.split(':');
    const col = data.collections?.[prefix] ?? {};
    return {
      name: id,
      source: 'Iconify',
      previewUrl: `https://icon-sets.iconify.design/${prefix}/${name}/`,
      license: { id: col.license?.spdx ?? col.license?.title ?? 'see collection', url: col.license?.url ?? `https://icon-sets.iconify.design/${prefix}/` },
      install: `npm i @iconify/react  →  <Icon icon="${id}" />   ·   SVG: https://api.iconify.design/${prefix}/${name}.svg`,
      notes: `${col.name ?? prefix}${col.author?.name ? ` by ${col.author.name}` : ''}${animated ? '; animated SVG (SMIL/CSS), respect prefers-reduced-motion' : ''}`,
    };
  });
  return { results, warnings };
}
```

```js
export function toMarkdown({ kind, query, results, warnings }) {
  const lines = [];
  if (!results.length) {
    lines.push(`No match for ${kind} "${query}". Try a broader or different term (e.g. a category, a mood, or an object name).`);
  } else {
    lines.push(`${results.length} ${kind} result${results.length > 1 ? 's' : ''} for "${query}":`, '');
    results.forEach((r, i) => {
      lines.push(`${i + 1}. **${r.name}** (${r.source})`);
      lines.push(`   Preview: ${r.previewUrl}`);
      lines.push(`   License: ${r.license.id} (${r.license.url})`);
      lines.push(`   Install: ${r.install}`);
      if (r.notes) lines.push(`   Notes: ${r.notes}`);
    });
    lines.push('', 'Verify the license fits this project before use. Nothing was installed.');
  }
  for (const w of warnings) lines.push(`Warning: ${w}`);
  return lines.join('\n') + '\n';
}
```

```js
import { parseArgs } from 'node:util';
import { tokenize } from './rank.mjs';

export class UsageError extends Error {}

export function parseCli(argv, { usage, options = {} }) {
  let parsed;
  try {
    parsed = parseArgs({ args: argv, allowPositionals: true, options: { limit: { type: 'string' }, json: { type: 'boolean' }, ...options } });
  } catch (e) {
    throw new UsageError(`${e.message}\n${usage}`);
  }
  const { values, positionals } = parsed;
  let limit = 3;
  if (values.limit !== undefined) {
    if (!/^-?\d+$/.test(values.limit)) throw new UsageError(`--limit must be a number.\n${usage}`);
    limit = Math.min(5, Math.max(1, Number(values.limit)));
  }
  return { values: { ...values, limit }, positionals };
}

export function requireQuery(q, usage) {
  if (!q || tokenize(q).length === 0) throw new UsageError(`Query must contain at least one word.\n${usage}`);
  return q.trim();
}
```

```js
#!/usr/bin/env node
import { pathToFileURL } from 'node:url';
import { parseCli, requireQuery, UsageError } from './lib/args.mjs';
import { ServiceError } from './lib/http.mjs';
import { searchFonts } from './lib/fonts.mjs';
import { searchIcons } from './lib/icons.mjs';
import { searchPacks } from './lib/packs.mjs';
import { toMarkdown } from './lib/format.mjs';

const USAGE = 'Usage: node materials.mjs <font|icon|animated-icon|pack> "<query>" [--limit 1-5] [--category <font category>] [--json]';
const KINDS = ['font', 'icon', 'animated-icon', 'pack'];

export async function main(argv, { fetchImpl, cacheDir, stdout = (s) => process.stdout.write(s), stderr = (s) => process.stderr.write(s) } = {}) {
  try {
    const { values, positionals } = parseCli(argv, { usage: USAGE, options: { category: { type: 'string' } } });
    const [kind, ...rest] = positionals;
    if (!KINDS.includes(kind)) throw new UsageError(`Unknown or missing kind "${kind ?? ''}".\n${USAGE}`);
    const query = requireQuery(rest.join(' '), USAGE);
    const deps = { limit: values.limit, fetchImpl, cacheDir };
    const res = kind === 'font' ? await searchFonts(query, { ...deps, category: values.category })
      : kind === 'icon' ? await searchIcons(query, deps)
      : kind === 'animated-icon' ? await searchIcons(query, { ...deps, animated: true })
      : await searchPacks(query, deps);
    stdout(values.json ? JSON.stringify({ kind, query, ...res }, null, 2) + '\n' : toMarkdown({ kind, query, ...res }));
    return 0;
  } catch (e) {
    if (e instanceof UsageError) { stderr(e.message + '\n'); return 1; }
    if (e instanceof ServiceError) { stderr(`Service error: ${e.message}. This is not an empty library; retry later or continue without it.\n`); return 2; }
    throw e;
  }
}

if (import.meta.url === pathToFileURL(process.argv[1] ?? '').href) {
  process.exitCode = await main(process.argv.slice(2));
}
```

```js
#!/usr/bin/env node
import { readFile, writeFile, readdir, mkdir, rm } from 'node:fs/promises';
import { existsSync } from 'node:fs';
import { join, relative, dirname, resolve } from 'node:path';
import { createHash } from 'node:crypto';
import { pathToFileURL } from 'node:url';

const MANAGED = ['reference', 'scripts'];

async function walk(dir) {
  if (!existsSync(dir)) return [];
  const out = [];
  for (const e of await readdir(dir, { withFileTypes: true })) {
    const p = join(dir, e.name);
    if (e.isDirectory()) out.push(...(await walk(p)));
    else out.push(p);
  }
  return out;
}

export async function buildExpected(pluginDir) {
  const repoRoot = resolve(pluginDir, '..', '..');
  const cfg = JSON.parse(await readFile(join(pluginDir, 'sync.json'), 'utf8'));
  const license = await readFile(join(repoRoot, 'LICENSE'));
  const notice = await readFile(join(repoRoot, 'NOTICE'));
  const toolsDir = join(pluginDir, 'tools');
  const toolFiles = (await walk(toolsDir)).filter((f) => !relative(toolsDir, f).startsWith('test'));
  const expected = new Map();
  for (const [skill, { guides = [], tools = false }] of Object.entries(cfg.skills)) {
    const base = `skills/${skill}`;
    const files = new Map();
    for (const g of guides) {
      const src = join(pluginDir, 'library', `${g}.md`);
      if (!existsSync(src)) throw new Error(`sync.json: skill "${skill}" lists unknown guide "${g}"`);
      files.set(`reference/${g}.md`, await readFile(src));
    }
    if (tools) for (const f of toolFiles) files.set(`scripts/${relative(toolsDir, f).split('\\').join('/')}`, await readFile(f));
    files.set('LICENSE', license);
    files.set('NOTICE', notice);
    const sums = [...files].sort(([a], [b]) => a.localeCompare(b))
      .map(([p, buf]) => `${createHash('sha256').update(buf).digest('hex')}  ${p}`).join('\n') + '\n';
    files.set('CHECKSUMS.sha256', Buffer.from(sums));
    for (const [p, buf] of files) expected.set(`${base}/${p}`, buf);
  }
  return { expected, skills: Object.keys(cfg.skills) };
}

async function actualManaged(pluginDir, skills) {
  const found = [];
  for (const s of skills) for (const m of MANAGED) {
    for (const f of await walk(join(pluginDir, 'skills', s, m))) found.push(relative(pluginDir, f).split('\\').join('/'));
  }
  return found;
}

export async function check(pluginDir) {
  const { expected, skills } = await buildExpected(pluginDir);
  const problems = [];
  for (const [p, buf] of expected) {
    const abs = join(pluginDir, p);
    if (!existsSync(abs)) problems.push(`missing ${p}`);
    else if (!(await readFile(abs)).equals(buf)) problems.push(`differs ${p}`);
  }
  for (const p of await actualManaged(pluginDir, skills)) if (!expected.has(p)) problems.push(`unexpected ${p}`);
  // CHECKSUMS differ whenever a file differs; report only the root cause.
  return problems.filter((x) => !(x.endsWith('CHECKSUMS.sha256') && problems.length > 1));
}

export async function apply(pluginDir) {
  const { expected, skills } = await buildExpected(pluginDir);
  const written = [], removed = [];
  for (const p of await actualManaged(pluginDir, skills)) {
    if (!expected.has(p)) { await rm(join(pluginDir, p)); removed.push(p); }
  }
  for (const [p, buf] of expected) {
    const abs = join(pluginDir, p);
    if (existsSync(abs) && (await readFile(abs)).equals(buf)) continue;
    await mkdir(dirname(abs), { recursive: true });
    await writeFile(abs, buf);
    written.push(p);
  }
  return { written, removed };
}

if (import.meta.url === pathToFileURL(process.argv[1] ?? '').href) {
  const args = process.argv.slice(2);
  const pluginDir = resolve(args.find((a) => !a.startsWith('--')) ?? 'plugins/ui');
  if (args.includes('--check')) {
    const problems = await check(pluginDir);
    if (problems.length) { console.error(`Skill copies are out of sync (run npm run sync):\n  ${problems.join('\n  ')}`); process.exitCode = 1; }
    else console.log('Skills in sync.');
  } else {
    const { written, removed } = await apply(pluginDir);
    console.log(`Synced: ${written.length} written, ${removed.length} removed.`);
  }
}
```

Note: the "differs" test expects exactly one problem; the CHECKSUMS filter above guarantees that. Empty directories left behind by removals are harmless.

```js
#!/usr/bin/env node
import { readFile, readdir } from 'node:fs/promises';
import { existsSync } from 'node:fs';
import { join, dirname, resolve, basename, relative } from 'node:path';
import { pathToFileURL } from 'node:url';

const FORBIDDEN = [/uizze/i, /npx impeccable/i, /impeccable context/i, /\{\{scripts_path\}\}/];
const EXEMPT_FILES = new Set(['LICENSE', 'NOTICE', 'CHECKSUMS.sha256']);

async function walk(dir) {
  const out = [];
  for (const e of await readdir(dir, { withFileTypes: true })) {
    const p = join(dir, e.name);
    if (e.isDirectory()) { if (e.name !== 'node_modules' && e.name !== 'test') out.push(...(await walk(p))); }
    else out.push(p);
  }
  return out;
}

function frontmatter(text) {
  const m = text.match(/^---\n([\s\S]*?)\n---/);
  if (!m) return null;
  const fm = {};
  for (const line of m[1].split('\n')) {
    const kv = line.match(/^([a-z-]+):\s*(.*)$/);
    if (kv) fm[kv[1]] = kv[2].replace(/^["']|["']$/g, '');
  }
  return fm;
}

export async function lintPlugin(pluginDir) {
  const problems = [];
  const skillsDir = join(pluginDir, 'skills');
  for (const e of existsSync(skillsDir) ? await readdir(skillsDir, { withFileTypes: true }) : []) {
    if (!e.isDirectory()) continue;
    const file = join(skillsDir, e.name, 'SKILL.md');
    const rel = `skills/${e.name}/SKILL.md`;
    if (!existsSync(file)) { problems.push(`${rel}: missing`); continue; }
    const text = await readFile(file, 'utf8');
    const fm = frontmatter(text);
    if (!fm) problems.push(`${rel}: missing frontmatter`);
    else {
      if (fm.name !== e.name) problems.push(`${rel}: name "${fm.name}" must equal "${e.name}"`);
      const len = (fm.description ?? '').length;
      if (len < 20 || len > 1024) problems.push(`${rel}: description length ${len} (20–1024)`);
    }
    if (text.split('\n').length > 120) problems.push(`${rel}: exceeds 120 lines`);
  }
  for (const f of await walk(pluginDir)) {
    const rel = relative(pluginDir, f).split('\\').join('/');
    if (EXEMPT_FILES.has(basename(f))) continue;
    if (!/\.(md|mjs|js|json)$/.test(f)) continue;
    const text = await readFile(f, 'utf8');
    text.split('\n').forEach((line, i) => {
      if (line.trimStart().startsWith('<!-- Adapted from')) return;
      for (const re of FORBIDDEN) if (re.test(line)) problems.push(`${rel}:${i + 1}: forbidden "${re.source.replace(/\\/g, '')}"`);
    });
    if (f.endsWith('.md') && rel.startsWith('skills/')) {
      for (const [, target] of text.matchAll(/\]\(([^)\s]+)\)/g)) {
        if (/^(https?:|mailto:|#)/.test(target)) continue;
        const path = target.split('#')[0];
        if (!existsSync(resolve(dirname(f), path))) problems.push(`${rel}: broken link ${path}`);
      }
    }
  }
  return problems;
}

if (import.meta.url === pathToFileURL(process.argv[1] ?? '').href) {
  const pluginDir = resolve(process.argv[2] ?? 'plugins/ui');
  const problems = await lintPlugin(pluginDir);
  if (problems.length) { console.error(`Lint failed:\n  ${problems.join('\n  ')}`); process.exitCode = 1; }
  else console.log('Lint clean.');
}
```
