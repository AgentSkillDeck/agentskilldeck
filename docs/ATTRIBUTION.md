# Attribution

agentatelier adapts material from Impeccable (Apache-2.0) and the uizze skills (Apache-2.0 and MIT). The full licence texts and copyright notices are in [NOTICE](../NOTICE), which ships in every skill folder. Each adapted file begins with a single-line `<!-- Adapted from … -->` provenance comment naming its source and commit. Line-by-line maps from every source instruction to where it now lives are in [docs/coverage/](coverage/).

Source repositories: uizze = `uizze-reference` clone (`skills/`) @ 146928e; Impeccable = `impeccable-reference` (`skill/reference/`) @ d631a88.
